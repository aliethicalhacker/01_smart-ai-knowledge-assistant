
# Smart AI Knowledge Assistant

A hands-on Python project developed through a
10-part AI learning series.

The goal is to build one practical AI application
while learning Python, machine learning, NLP,
large language models, and document retrieval.

## Part 1: Python Foundations

### Features
- Interactive command-line interface
- Rule-based responses
- Input normalization
- Personalized greeting
- Basic input validation

### Technologies
- Python 3
- VS Code
- Google Colab
- Git and GitHub

### Project structure

```text
smart-ai-knowledge-assistant/
├── main.py
├── README.md
├── .gitignore
└── notebooks/
    └── Part_01_AI_Assistant.ipynb
```

### Run locally

```bash
python main.py
```

On Windows, you can also try `py main.py`.

### Current limitations

This is a rule-based prototype, not a trained AI model.
It cannot answer arbitrary questions intelligently yet.
